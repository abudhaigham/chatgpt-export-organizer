# Security Policy

## Supported versions

Security fixes are provided for the latest release.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability
reporting feature. Do not open a public issue containing sensitive export data.

Include a minimal synthetic reproduction. Never attach a real ChatGPT export,
conversation JSON, `.dat` asset, or generated chat PDF.

## Scope

Security-sensitive areas include path traversal, unsafe overwrites, filename
collisions, accidental disclosure, malformed export handling, and dependency
issues in optional PDF rendering components.
